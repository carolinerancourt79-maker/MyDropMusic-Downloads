MY DROP MUSIC SYNC 6.22.45

Compagnon Windows avec transfert HTTPS rapide et interface français/anglais.
L'installateur conserve le dossier, le code de jumelage et le certificat existants.
Fermer l'ancien compagnon avant d'installer la mise à jour.

Pour construire sur Windows : CREER_EXE_WINDOWS.bat, puis
CREER_INSTALLATEUR_WINDOWS.bat (Inno Setup 6 nécessaire).
Le testeur utilise l'installateur ou l'EXE; Python n'est pas nécessaire.

Le téléchargement officiel reste :
https://github.com/carolinerancourt79-maker/MyDropMusic-Downloads/releases/latest
