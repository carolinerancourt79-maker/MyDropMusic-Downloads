MyDropMusic Sync pour Windows

Le compagnon Windows de MyDropMusic permet de transférer votre musique vers votre iPhone par Wi-Fi.

Téléchargement

Télécharger l’installateur Windows — version 6.22.11 de test
https://github.com/carolinerancourt79-maker/MyDropMusic-Downloads/releases/tag/v6.22.11-test

Dans la section Assets, choisissez MyDropMusicSync_Setup_6_22_11.exe. Les archives « Source code » ne sont pas nécessaires pour l’installation.

Installation et synchronisation

Téléchargez et lancez l’installateur.

Ouvrez MyDropMusic Sync sur votre PC.

Choisissez le dossier contenant votre musique.

Connectez le PC et l’iPhone au même réseau Wi-Fi.

Dans MyDropMusic sur l’iPhone, ouvrez Smart Sync, puis scannez le QR code affiché sur le PC.

Gardez le compagnon Windows ouvert pendant le transfert.

Smart Sync transfère les chansons manquantes ou modifiées, sans recopier celles déjà à jour. Les transferts sont chiffrés par HTTPS.

Version de test

Cette version nécessite MyDropMusic 6.22.11 sur iPhone.

L’installateur Windows n’est pas signé numériquement : Windows peut afficher un avertissement. Téléchargez-le uniquement depuis ce dépôt officiel.

L’application iPhone n’est pas distribuée dans ce dépôt.
